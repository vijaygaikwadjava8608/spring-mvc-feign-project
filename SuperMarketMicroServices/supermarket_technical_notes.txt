First Approch
We have deployed jar file to Azure app services
1. you have azure account
2. you need azure pluging into your pom.xml
<plugin>
				<groupId>com.microsoft.azure</groupId>
				<artifactId>azure-webapp-maven-plugin</artifactId>
				<version>2.9.0</version>
			</plugin>
			
3. Need to execute maven command in ide azure-webapp:config
this will configure azure configuration 
prompt will asked some configuration

4. Modify autogenerated code configuration if needed
5. Next go to the project location and use the mvn azure-webapp:deploy command to deploy the jar file to azure app service.
